# Directorio SdS - Gangster MMO RPG

Este directorio contiene el proyecto Godot "Gangster MMO RPG".

## 📁 Estructura del Directorio

```
SdS/
├── gangster-mmo-rpg/      # 🎮 PROYECTO PRINCIPAL DE GODOT
│   ├── assets/            # Recursos del juego
│   ├── scenes/            # Escenas de Godot
│   ├── scripts/           # Scripts GDScript
│   ├── docs/              # Documentación del proyecto
│   ├── project.godot      # Archivo de configuración del proyecto
│   └── README.md          # Documentación principal del juego
│
├── godot-engine/          # Ejecutables del motor Godot
│   ├── Godot_v4.5-stable_win64.exe
│   └── Godot_v4.5-stable_win64_console.exe
│
└── sd-s/                  # (Proyecto de prueba vacío - puede eliminarse)
```

## 🚀 Cómo Abrir el Proyecto

1. Navega a la carpeta `godot-engine/`
2. Ejecuta `Godot_v4.5-stable_win64.exe`
3. En Godot, abre el proyecto desde: `gangster-mmo-rpg/project.godot`

## 📖 Documentación

Para más información sobre el proyecto, consulta:
- `gangster-mmo-rpg/README.md` - Descripción completa del juego
- `gangster-mmo-rpg/docs/SETUP.md` - Guía de configuración
- `gangster-mmo-rpg/docs/scene-setup-guide.md` - Guía de configuración de escenas

## 🎯 Proyecto Principal

El proyecto principal es **gangster-mmo-rpg**, un MMO RPG 3D con estética chunky pixel art y temática de gangsters.
