## Notas de Uso

- **Todas las imagenes son de referencia.** No deben usarse directamente en el juego.
- Los nombres de archivo mantienen el formato original de descarga (con numero inicial para orden de coleccion).
- Las imagenes estan en formato PNG, en la carpeta `design/references/`.
- Para assets definitivos, se crearan modelos 3D Low Poly originales basados en estas referencias.
- Algunos archivos cubren multiples categorias (ej: `7_Top_free_game_assets_tagged_Crime.png` contiene arquitectura, personajes y armas).

### Convencion de Nombres
```
[NUMERO_ORDEN]_[DESCRIPCION_BREVE]_[FUENTE/ESTILO].png
```
